# 문구 톤 맞추기

화면 문구를 **우리 말투 규칙**에 맞게 점검하고, 바꿀 문구를 제안하는 매뉴얼이에요.

## 두 가지 쓰임

- **화면 점검** — 화면(또는 플로우) 전체 문구를 규칙 8개로 보고 표로 제안해요.
- **문구 다듬기** — 사용자가 준 문구나, AI가 새로 쓰는 문구(예: 경고·안내)를 규칙에 맞춰요. Figma 호출 없음.

## 순서 (화면 점검)

1. **범위 받기** — 어떤 화면·플로우인지 물어요.
2. **Figma 문구 모으기** — `design-system/figma-log.md`·이미 읽은 기록을 먼저 써요. 없을 때만 Figma MCP로 읽고 바로 기록해요.
3. **코드 문구 모으기** — `app/prototype/…`, 화면 공통 틀, `mocks/`의 화면 문구(제목·안내·버튼·선택지·placeholder·경고).
   - **사용자가 쓴 글의 예시**(더미데이터의 코멘트·조언 내용)와 **이름 같은 데이터**는 대상이 아니에요.
4. **규칙 8개로 점검** — 걸리는 문구마다 어느 규칙인지 적어요. 같은 문구가 Figma와 코드에 다르게 있으면 그것도 적어요.
5. **보고** — 아래 보고 형식. **바로 고치지 않아요.** 사용자가 고른 것만 코드에 반영해요.
6. **반영할 때** — 선택지 글자를 바꾸면 화면 파일의 `selected`·`links`(선택지 글자를 열쇠로 써요)도 같이 바꾸고, `npm run check`·화면이 열리는지 확인해요.

## 기준 (사용자가 고른 8개)

**말투**
1. **해요체로 통일** — “~해요 / ~어요”. “합니다·하세요·하십시오”는 쓰지 않아요.
2. **이름으로 부르기** — “사용자님·회원님” 대신 **이름 + 님** (예: “재원님의 면접관이 되어”).
3. **느낌표는 완료·칭찬·혜택에만** — 예: “복사가 완료됐어요!”, “무료 면접 이용권 획득!”. 안내·경고에는 쓰지 않아요.
4. **막을 때도 “할 수 있어요”로** — 못 하는 이유 대신 할 수 있는 방법을 말해요. 예: “6개의 항목을 모두 선택하면 제출할 수 있어요” (○) / “선택하지 않으면 제출할 수 없습니다” (✗)

**표기**
5. **띄어쓰기·맞춤법 교정** — 예: 대체로맞춰요 → 대체로 맞춰요, 마무리 했어요 → 마무리했어요, 가만히못있음 → 가만히 못 있어요
6. **선택지 끝말은 “~요”(해요체)** — 예: 자주 몸흔듦 → 자주 몸을 흔들어요. 길어져서 칸에 안 들어가면 표의 메모에 적어요.
7. **“~해 주세요”는 띄어 쓰기** — 예: 남겨주세요 → 남겨 주세요, 적어주세요 → 적어 주세요
8. **딱딱한 말 대신 쉬운 말** — 사용자가 하는 행동으로 말해요 (예: 입력 → 적기). 바꿀지 애매하면 **확인 필요**로 물어요.

## 보고 형식

|---|---|---|---|---|---|
| 1 | 선택지 (1:1293) / mocks/friend-feedback.ts | 대체로맞춰요 | 대체로 맞춰요 | 5 | |
| 2 | 경고 / CommentInput.tsx | 100자 이내로 입력해 주세요 | 100자 이내로 적어 주세요 | 8 | |

## 규칙

- **바로 고치지 않아요.** 전/후를 보여 주고 사용자가 고른 것만 반영해요.
- **Figma를 고치지 않아요.** Figma 문구는 표로 넘기고 디자이너가 고쳐요.
- **뜻을 바꾸지 않아요.** 말투만 다듬고 숫자·조건·대상(6개, 72시간, 100자, 2명 등)은 그대로 둬요.
- **모르는 건 추측하지 않아요.** 규칙에 없는 경우(서비스 이름 표기, 전문 용어 등)는 **확인 필요**로 묻고, 정해지면 이 파일 기준에 한 줄 추가해요.

## 만든 이유

- 2026-11-12: Hilit 지인 피드백 화면에 “잘 맞춰요/자주 몸흔듦”처럼 끝말이 섞이고, “남겨주세요”와 AI가 쓴 “입력해 주세요”처럼 표기가 달라서, 문구를 새로 쓸 때마다 톤이 흔들렸어요. 우리 말투 규칙을 한 곳에 모아 점검하려고 만들었어요.
