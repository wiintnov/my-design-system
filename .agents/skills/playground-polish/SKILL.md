# Playground 다듬기

/playground는 **디자이너가 Figma와 대조하는 검수 화면**이에요. 예쁘게보다 **비교하기 쉽게**가 목표예요.

## 순서

1. 사용자에게 무엇이 불편한지 한 문장으로 확인해요. 모호하면 아래 체크리스트에서 골라 달라고 해요.
2. `app/playground/` 안의 파일만 고쳐요. **`components/ui/`의 컴포넌트 자체는 건드리지 않아요.** (컴포넌트 수정은 `build-component`)
3. 고친 뒤 무엇이 달라졌는지 화면 기준으로 설명하고, 새로고침해 보라고 안내해요.

## 체크리스트 (자주 나오는 불편)

- [ ] 각 견본에 **토큰 이름 + 실제 값(hex/px)** 이 같이 보이는가
- [ ] 모든 variant × size × state가 **한 표**에 보이는가
- [ ] Hover·Pressed·Focus를 **고정 상태로** 볼 수 있는가 (마우스를 안 올려도)
- [ ] 밝은 배경 / 어두운 배경 전환으로 볼 수 있는가
- [ ] 실제 크기(1x)로 보이는가, 확대 보기가 필요한가
- [ ] 섹션 순서가 Figma 페이지 순서와 같은가
- [ ] 모바일 폭(375px)에서도 깨지지 않는가

## 규칙

- playground 화면도 토큰 클래스만 써요 (자동 검사 대상).
- 새 라이브러리를 설치하지 않아요.
