# 4px 그리드 · 토큰 규칙 검사

## 순서

1. **코드 검사** — `npm run check` 실행. 결과를 아래 표로 바꿔 보여줘요.
2. **Figma 검사 (요청 시)** — 사용자가 Figma 프레임 링크를 주면 `get_design_context`로 읽고 간격·크기·모서리 값을 같은 기준으로 봐요. `figma-log.md` 먼저 확인.
3. **보고** — 표 하나로:

   | 어디 | 값 | 문제 | 고칠 곳 |
   |---|---|---|---|
   | Figma › Button/M › padding | 3px | 4px 그리드 밖 | Figma (4px로) |
   | components/ui/Chip.tsx:12 | `#FF0000` | 색 직접 입력 | 코드 (토큰으로) |

4. **고치기** — 사용자가 고르게 해요.
   - Figma에서 온 값이 문제면: **Figma에서 고치고** → `figma-sync`로 다시 가져오기.
   - 코드에서 생긴 문제면(색 직접 입력, 임의값): 토큰 클래스로 바꾸기.

## 기준

- 오류: 2의 배수가 아닌 px (1, 3, 5…), 컴포넌트 안의 #hex·rgb.
- 경고: 2의 배수지만 4의 배수가 아닌 px (작은 요소만 허용), 4의 배수인 임의값 (기본 스케일로 바꿀 수 있음).
- 글자 크기·줄 높이는 그리드 검사 대상이 아니에요.
- **임의값으로 우회해서 오류를 없애지 않아요.**
