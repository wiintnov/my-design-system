# 더미데이터 만들기

## 순서

1. **무엇이 필요한지 표로** — 화면(또는 Figma 프레임)을 보고 필요한 데이터 항목을 정리해 확인받아요.

   | 데이터 | 항목 | 개수 | 경계 케이스 |
   |---|---|---|---|
   | 상품 | 이름, 가격, 이미지, 할인율 | 12 | 이름 아주 김, 가격 0원, 품절 |

2. **만들기** — `mocks/<이름>.ts`에 TypeScript 배열로 `export` 해요. 타입도 같이 적어요.
3. **연결** — 화면이 `mocks/`에서 데이터를 불러와 그리게 바꿔요.
4. **확인** — 경계 케이스에서 화면이 깨지지 않는지 사용자에게 보여 줘요. 깨지면 Figma에 그 상태 디자인이 있는지 물어요.

## 규칙

- 실존 인물 이름·전화번호·이메일·주소·회사명은 쓰지 않아요. 예시용임이 티 나는 값으로 (예: 010-0000-0000, user@example.com).
- 이미지는 `public/`의 자리표시 이미지나 단색 박스로. 외부 사진 링크를 쓰지 않아요.
- 서버·데이터베이스를 만들지 않아요. 파일 안의 가짜 데이터까지만.
