# 프로토타입 화면 만들기 · 유저플로우 연결

## 순서

1. **플로우 먼저 정하기** — 사용자에게 유저플로우를 물어요. Figma/FigJam 유저플로우 링크가 있으면 받아서 읽고, 없으면 “화면 이름을 순서대로 말해 주세요”. 결과를 표로 확인받아요.

   | 순서 | 화면 이름 | 다음 화면으로 가는 조건 |
   |---|---|---|
   | 1 | 상품 목록 | 상품 카드 누르면 |
   | 2 | 상품 상세 | ‘구매하기’ 누르면 |

2. **한 화면씩** — 화면 프레임 링크를 받아 `get_design_context`로 읽어요 (`design-system/figma-log.md` 먼저 확인).
3. **만들기** — `app/prototype/<플로우-영문>/<순서>/page.tsx`.
   - `components/ui/`에 있는 컴포넌트를 먼저 써요. 없는 컴포넌트가 반복되면 `build-component`로 먼저 만들자고 제안해요.
   - 데이터가 필요하면 `mocks/`의 더미데이터를 써요. 없으면 `dummy-data` 스킬로 먼저 만들어요.
   - 모바일 화면이면 가운데 정렬된 375px 폭 틀 안에 그려요.
4. **연결** — 플로우 표의 조건대로 버튼·카드에 `next/link`로 다음 화면을 연결해요. 마지막 화면에는 “처음으로” 링크.
5. **등록** — `prototype/screens.ts`에 `{ flow, step, title, href, figma }`를 추가해 `/prototype` 목록에 보이게 해요.
6. **확인** — `npm run check` → 사용자에게 `/prototype`에서 첫 화면부터 눌러 보라고 안내해요.

## 규칙

- 토큰 클래스만 써요. 색 직접 입력·임의값 금지 (자동 검사가 잡아요).
- 진짜 로그인·결제·서버 저장은 만들지 않아요. 누르면 다음 화면으로 넘어가는 **흉내**까지만.
- Figma에 없는 화면·상태를 지어내지 않아요. 필요해 보이면 사용자에게 물어요.
