# 디자이너가 처음 만들기 좋은 스킬·서브에이전트

사용자가 “뭘 만들면 좋을지 모르겠어”라고 하면 이 중 상황에 맞는 2~3개를 제안해요.
기준은 **매주 한 번 이상 반복하는 일**인지예요.

| 이름(예) | 종류 | 무엇을 | 이런 사람에게 |
|---|---|---|---|
| `handoff-check` | 스킬 | 넘기기 전 빠진 상태·변수 미연결·그리드 밖 값 점검 | 개발 핸드오프가 잦다 |
| `state-coverage` | 스킬 | 빈 화면·로딩·에러·권한 없음 상태가 다 있는지 확인 | 화면 설계를 많이 한다 |
| `copy-tone` | 스킬 | 버튼·안내·에러 문구를 우리 서비스 말투로 맞춤 | 문구를 직접 쓴다 |
| `feedback-filter` | 스킬 | 받은 디자인 피드백을 “사용자 문제 / 취향 / 정책” 으로 나눠 우선순위 정리 | 리뷰를 많이 받는다 |
| `token-naming` | 스킬 | 새 Variables 이름을 팀 규칙대로 지어 줌 | 디자인 시스템 담당 |
| `a11y-reviewer` | 서브에이전트 | 대비·터치 영역·포커스 검사, 보고만 | 접근성을 챙겨야 한다 |
| `screen-auditor` | 서브에이전트 | 화면 하나에 쓰인 값이 전부 토큰인지 전수 조사, 보고만 | 화면 수가 많다 |

틀은 `skill-template.md`, `agent-template.md`에 있어요.
