# 나만의 템플릿으로 키우기

> 이 키트는 **출발점**이에요. 목표는 이 레포가 **“내가 일하는 방식이 담긴 템플릿”** 이 되는 거예요.
> 다음 프로젝트를 시작할 때, 혹은 동료가 합류할 때 내 템플릿에서 시작하면
> 내가 쌓은 기준과 스킬이 그대로 따라와요.

## 무엇이 “내 것”이 되나요

| 층 | 처음 (키트 기본) | 키운 뒤 (내 템플릿) |
|---|---|---|
| 사내 규정 `AGENTS.md` | 4px 그리드, 토큰만 | + 우리 팀 네이밍, 금지 패턴, 말투 |
| 토큰 `globals.css` | 예시 값 | 내 디자인 시스템 기본 토큰 |
| 컴포넌트 `components/ui` | 버튼 1개 | 자주 쓰는 기본 컴포넌트 묶음 |
| 스킬 `.claude/skills` | 10개 | + 내가 만든 스킬 (핸드오프 점검, 아이콘 정리…) |
| 서브에이전트 `.claude/agents` | 1명 | + 내가 만든 검수 동료 |
| 자동 검사 `scripts/` | 4px·색 | + 내 팀 규칙 (예: 그림자 토큰만) |

## 5단계 성장 경로

### Lv.1 따라 하기
- “시작하자”로 `PROGRESS.md` 1~10단계를 끝까지.
- **완료 신호:** 배포 링크에서 유저플로우를 처음부터 끝까지 테스트했다.

### Lv.2 규칙을 내 것으로
- 일하면서 “아 이건 이렇게 해야지” 싶은 순간마다:
  `이 규칙 AGENTS.md에 추가해줘: [규칙]`
- 맞지 않는 기본 규칙은 지우거나 고쳐요. 이 키트의 규칙은 제안일 뿐이에요.
- **완료 신호:** 같은 지적을 두 번 하지 않게 됐다.

### Lv.3 스킬 만들기
- `docs/skill-backlog.md`에서 가장 자주 나온 것 하나를 골라:
  `skill-backlog의 [항목]을 스킬로 만들어줘`
- 가이드: [스킬 만들기](1-skill-guide.md)
- **완료 신호:** 예전엔 길게 설명하던 일을 `/스킬이름`(Codex는 `$스킬이름`) 한 마디로 끝낸다.

### Lv.4 동료 만들기
- 검수·조사처럼 결과만 보면 되는 일을 서브에이전트로.
- 가이드: [서브에이전트 만들기](2-subagent-guide.md)
- **완료 신호:** 검수는 맡기고 결과 표만 본다.

### Lv.5 내 템플릿으로 공개
- AI에게: `my-template 스킬로 이 레포를 내 템플릿으로 정리해줘`
- `my-template` 스킬이 하는 일:
  1. 이 프로젝트에만 해당하는 것(특정 화면, 임시 메모)과 **다음에도 쓸 것**을 나눠 표로 보여줘요
  2. 남길 것만 남기고, `README.md`를 내 템플릿 소개로 다시 써요
  3. `CHANGELOG.md`에 이 키트에서 무엇을 바꿨는지 기록해요
  4. GitHub에서 템플릿으로 지정하는 방법을 안내해요 (Settings › Template repository 체크)
- **완료 신호:** 동료가 내 레포의 **Use this template**으로 시작한다.

## 계속 키우는 습관

- **회고 한 줄:** 작업이 끝날 때마다 `오늘 반복한 부탁 있었어? skill-backlog에 적어줘`
- **가지치기:** 한 달에 한 번 `안 쓰는 스킬이나 겹치는 스킬 있는지 봐줘`
- **버전 남기기:** 규칙·스킬을 크게 바꾸면 커밋 메시지에 이유를 적어요. 나중에 “왜 이 규칙이 생겼지?”의 답이 돼요.

## 원본 키트의 업데이트를 받고 싶다면

템플릿으로 만든 레포는 원본과 연결이 끊겨요. 원본에 좋은 스킬이 추가되면
`원본 키트(github.com/HoberMin/ai-native-designer-kit)에서 [스킬이름] 스킬만 가져와줘`
라고 하면 AI가 그 파일만 복사해 와요.
